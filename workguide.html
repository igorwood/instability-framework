1.2 采集接口

# World Bank：单国多年
https://api.worldbank.org/v2/country/{ISO3}/indicator/{CODE}
  ?format=json&date=2014:2024&per_page=500

# World Bank：多国横向
https://api.worldbank.org/v2/country/A;B;C/indicator/{CODE}
  ?format=json&date=2014:2024&per_page=500

# IMF 债务（注意：路径里的国家过滤会被忽略，返回全球）
https://www.imf.org/external/datamapper/api/v1/GGXWDG_NGDP
  → 解析时按 iso3 自行筛选

1.3 三条采集纪律

  1. 不要伪装 User-Agent 访问 FRED——手写 Chrome UA 会被限流挂起，默认 UA 反而返回 200。
  2. HTTP 200 不等于内容完整——实测中曾遇到 JSON 在数百 KB 处截断却返回 200，直到解析时才暴露。
  3. 字段名不等于字段内容——NAVCO 的 loc_iso 实际是 COW 国家代码的浮点字符串；World Bank 的 indicator 接口不返回 region，需单独查 country 端点。

2. 步骤一：L0 可测性检查

2.1 检查表达空间

取最近一年的 GOV_WGI_VA.SC。

数值判定下一步
≥ 70可测，效度高继续 L1
40 – 70可测，但需注意趋势继续 L1，并记录十年趋势
< 40不可测先看 2.3 的例外判定

2.2 检查数据连续性

对每个核心指标，检查是否有年份缺失或突然中断。

发现中断时：记录中断的具体月份。中断时点本身是信息——实测中曾观察到某国的生产价格指数在一个地缘政治断裂的月份同时停更。

2.3 表达空间 < 40 时的例外判定

重要 不要一看到表达空间 < 40 就判 C。还要看政府效能：
组合判定依据
表达 < 40 且 效能 > 80不判 C高效能意味着秩序有其他来源
表达 < 40 且 效能 40–80判 C制度质量不足以自我支撑，稳定部分来自压制
表达 < 40 且 效能 < 40判 C，且形态为 D 或 E低能力 + 低表达，数据本身可能不可靠

2.4 覆盖率检验（有事件数据时）

计算事件计数与覆盖率代理的相关系数。

  • |r| < 0.3：计数可近似当作信号
  • 0.3 ≤ |r| ≤ 0.5：计数需作为协变量控制
  • |r| > 0.5：计数不可直接使用——改用「事件数 ÷ 覆盖率」的比率

参考基准：实测中某联邦制大国的州级数据曾达到 r≈0.60、R²≈0.36。

2.5 本步产出

写下三行判定，缺一不可：

表达空间：{数值}（{年份}）→ {可测/不可测}
数据连续性：{完整/中断于 YYYY-MM}
覆盖率检验：{r 值} 或「无事件数据，未做」

3. 步骤二：L1 路径判定

3.1 取五个治理维度

计算各维度与表达空间的差值，找出最短板。

差值模式含义路径倾向
五维齐平（差距 < 10）治理结构均衡表达型 / 中间型
反腐显著偏低（差 > 15）能执行但缺监督容量不足型
效能显著偏高（> 80）强行政、可参与度有限高质量低参与型
全维中等（40–55）制度质量不足压制型

3.2 四类路径的判定式

if 表达空间 > 70 and 政府效能 > 70:
    路径 = 表达型
elif 表达空间 > 45 and 政府效能 < 55:
    路径 = 容量不足型
elif 表达空间 < 45 and 政府效能 < 70:
    路径 = 压制型
elif 表达空间 < 60 and 政府效能 > 80:
    路径 = 高质量低参与型
else:
    路径 = 中间型（需个案判断）

3.3 必须记录的反例

判定路径时，主动检查两个反直觉情况：

  1. 低失业 + 高通胀 → 可能是战时动员型经济（实测中曾出现失业率最低、但 CPI 十年近乎翻倍的组合）
  2. 高债务 + 低风险 → 可能是本币债务或制度性储备（实测中曾出现债务率超过 160% 但实际无净债务的经济体）

4. 步骤三：L2 动态分析

4.1 分层计算

对每个经济指标，算两个相关系数：

层次算法含义
混合相关直接算指标与政治稳定的 Pearson r「哪些国家更不稳」
国家内相关先减去各国均值，再算 r「一个国家何时变得更不稳」
关键判断 两个系数方向相反时，以国家内相关为准。混合相关大半是国家间差异的产物。

4.2 已知基准值（多国面板实测）

指标混合 r国内 r结论
通胀率−0.55−0.38唯一跨层稳健
人均 GDP+0.60−0.55符号反转（托克维尔效应）
进口占 GDP+0.64+0.00纯国家间差异
失业率−0.24+0.11方向翻转

4.3 趋势检查

对政治稳定与表达空间，必须画出十年逐年序列，不能只看首末两点。

需要特别注意的形态：

  • 单调下降：结构性退化（实测中曾见表达空间十年下降逾 10 分）
  • 回升后急跌：比单调下降更危险（先回升约 4 分，次年跌回并创新低）
  • 异常平坦：低表达空间下的测量稳定性，不是真实稳定（十余年波动不足 5 分）

5. 步骤四：L3 因果识别（可选）

何时可以跳过 绝大多数分析做不到 L3。跳过时，结论形态固定为 B，且报告中必须明确写「这是相关，不是因果」。

5.1 识别设计的四个条件

条件检验方法不通过时
平行趋势画处理组与控制组冲击前的序列改用合成控制法
无预期效应确认冲击不可预测天灾可用，政策不可用
无溢出检查地理/经济隔离缩小控制组范围
排他性论证冲击只通过一条通道放弃因果结论

5.2 推荐的做法

本项目第二版设计：DID + 双向固定效应。

关键点：双向固定效应吸收「全国共同趋势」——那正是纯预测路径失败的地方（预测力全部来自事件自相关）。这是设计消掉它，不是回避它。

6. 步骤五：L4 结论撰写

6.1 先定形态，再写结论

形态允许的表述禁止的表述
A「X 导致 Y，效应量为 Z」超出样本外推
B「当前水平是 X，趋势是 Y」「将在某年失稳」
C「数据存在，但含义受限」「该国更稳定」
D「数据不足，无法判断」任何数值结论
E「未发现稳定关系」「不存在关系」

6.2 三种结案类型必须分开写

类型含义写法
否证数据充分且关系不成立「假设 X 被否证」
不可判定数据或设计缺失，换人也做不了「无法检验」
未检验数据在，但本研究没做「未做」
常见错误 把「不可判定」和「未检验」都写成「未获支持」——这会极大夸大否定范围，让读者以为整个方向都被否定了。

6.3 结论段的标准结构

  1. 形态声明：本分析达到形态 X
  2. 可说的：当前水平、趋势、路径归属
  3. 不可说的：明确列出不能下的判断
  4. 最要紧的一条：一句话总结

7. 常见错误与处理

错误症状处理
把「事件少」当「稳定」结论中出现「该国很稳定」而未经 L0回到步骤一，检查表达空间
把混合相关当因果引用跨国回归系数预测单国未来补算国家内相关
跨政体比较事件计数直接比较不同制度下的事件数量构念不等价，改为定性比较
从局部无推全局无「这份名单里没有」→「样本里没有」核对完整数据集，而非子集
忽略数据中断用了停更年份之后的数据标记断裂点，缩小时间窗
把低失业当稳定未检查是否为动员经济并列看通胀与 FDI
把债务存量当压力未区分本币债与外币债检查债权人结构与储备
用「未检验」冒充「否证」结案表全部标成「不支持」按 6.2 三类分开

9. 质量检查清单

提交前逐项打勾。任一项不通过，退回相应步骤。

□检查项依据
□表达空间已记录，且判定与阈值一致步骤 2.1
□数据中断点已标注（若有）步骤 2.2
□路径判定有明确依据，不是印象步骤 3.2
□经济指标同时算了混合与国内相关步骤 4.1
□政治稳定画了逐年序列，不只看首末步骤 4.3
□结论形态已声明（A/B/C/D/E）步骤 6.1
□三种结案类型没有混用步骤 6.2
□报告中每个数字都能从数据库复算产出物
□局限声明含数据缺口、时点、因果限制产出物
□没有把「不可测」写成「更稳定」框架 L4
最后一条 如果你的报告里出现「该国很稳定」这类判断，而前面没有 L0 的检查记录——删掉这个判断，回到步骤一。
