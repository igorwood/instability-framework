## 核心主张

> 在问「哪个指标能预测不稳定」之前，必须先问「这个国家的不稳定能不能被观测」。

框架是**五层门控**的，前一层不过，后面做了也是白做：

| 层级 | 问题 | 不通过的后果 |
|---|---|---|
| **L0 可测性** | 不稳定能被看见吗 | 后面全部无效，且会得出反向结论 |
| **L1 结构条件** | 处在哪种失稳路径上 | 用错路径会误判风险方向 |
| **L2 动态变化** | 什么时候变得更不稳 | 混同「国家间差异」与「国内变化」 |
| **L3 因果识别** | 是什么导致的 | 相关当因果 |
| **L4 结论形态** | 能说到什么程度 | 过度承诺 |

---

## 四条路径

| 路径 | 特征 | 判定信号 |
|---|---|---|
| **表达型** | 可见、渐进、可控 | 表达空间高 + 制度容量高 |
| **容量不足型** | 可见、慢性难收敛 | 表达空间中 + 制度容量低 |
| **压制型** | 不可见、突变 | 表达空间低 + 制度质量中等 |
| **高质量低参与型** | 可见但受控 | 表达空间中 + 制度质量极高 |

第四类是在跨国对比后新增的：**同样是低表达空间，秩序可以由制度质量或强制力维持，两者的稳定性质完全不同。**

---

## 五种结论形态

| 形态 | 含义 | 触发条件 |
|---|---|---|
| **A** | 能测水平 + 能测时点 | L0 与 L3 均通过 |
| **B** | 仅能测水平 | L0 通过、L3 不通过 |
| **C** | 事件不可观测 | L0 不通过 |
| **D** | 数据不足 | 数据源不可用 |
| **E** | 无信号 | 数据充分但无稳定关系 |

---

## 主要发现

1. **没有任何经济指标在所有国家内部方向一致**——不存在普适的「失业率上升 X% 导致不稳定」。
2. **通胀是唯一跨层稳健的因素**：混合相关与国内相关同向。
3. **人均 GDP 出现符号反转**：跨国看富国更稳，国内看增长期反而不稳（托克维尔效应）。
4. **新闻事件层是硬约束**：主流事件数据库在实测中不可用，所有事件级分析都做不了。

## 数据源

- **World Bank** — WGI 治理指标、宏观统计
- **IMF** — 政府债务（Datamapper）
- **FRED / Eurostat** — 生产价格指数
- **NAVCO** — 非暴力与暴力运动结果数据集

## 边界声明

本框架用于**描述性风险因素分析**——产出是风险地图，不是操作方案。

前者可用于预警、资源配置、政策评估；后者涉及介入他国政治，不在框架范围内。
