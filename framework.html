1. 框架解决什么问题

研究国家不稳定性最容易犯的错误，是直接跳到指标与模型。本项目用多年研究、两轮设计和数百项自动化测试换来的教训是：

核心命题 在问「哪个指标能预测不稳定」之前，必须先问「这个国家的不稳定能不能被观测」。

所以框架是五层的，而且层与层之间是门控关系——前一层不过，后面做了也是白做。

层级问题不通过时的后果
L0 可测性这个国家的不稳定能被看见吗后面全部无效，且会得出反向结论
L1 结构条件它处在哪种失稳路径上用错路径会误判风险方向
L2 动态变化它什么时候变得更不稳混同「国家间差异」与「国内变化」
L3 因果识别是什么导致的相关当因果
L4 结论形态能说到什么程度过度承诺

2. L0 — 可测性前置判断

2.1 为什么必须先做

初期的核心教训：事件计数与观测覆盖率高度相关（回归 R²≈0.36，r≈0.60）。

也就是说，「抗议变多了」可能只是「报道变多了」。不先处理这一点，后面所有模型都在拟合记录过程，不是社会过程。

该阶段的模型最终被置换检验自行揭穿：真实 AUC≈0.72，而特征置换后的 AUC≈0.72（约 49% 分位）——模型的预测力全部来自事件自身的自相关，宏观特征零贡献。

2.2 三项检查

检查方法不通过的判据
表达空间WGI GOV_WGI_VA.SC（表达与问责）低于 40 → 可见冲突被系统性抑制
数据连续性关键指标是否有突然中断任一核心指标在某月/年停更 → 标记制度性断裂
报道覆盖率事件数 ÷ 覆盖率代理，看比值是否漂移相关性 > 0.5 → 计数不可直接使用

2.3 判定的典型形态

在实测样本中，表达空间与制度质量的组合呈现四种典型形态（下表为分布描述，不含具体国别数据）：

表达空间区间典型判定处理方式
≥ 70可测，效度高直接进入 L1
50 – 70可测，需关注趋势记录十年趋势，警惕持续下滑
40 – 50可测但接近警戒线L0 只过「两项半」，结论需加保留
< 40不可测判 C，或按 §2.4 的例外条件重判

「不可测」不是「不研究」，而是「结论形态受限」（见 L4）。

2.4 一个反直觉的实证

在实测中曾观察到：某国的生产价格指数在某个特定月份起停止更新，而该月恰好对应一次重大的地缘政治断裂。

数据中断的时点本身就是信息：当某项统计在特定月份突然停更，那个月份往往标记着制度性断裂。这一观察促使框架把「数据连续性」列为 L0 的独立检查项。

重要修正 本框架早期版本曾断言「压制型国家的运动不可见，不会进入样本」。后续用全样本数据集检验推翻了这一点：低表达空间的国家同样出现在样本中。准确说法是：它们在样本中有记录，但数量与类型可能系统性偏少——这是量的偏差，不是存在与否的偏差。

3. L1 — 结构路径分类

通过 L0 后，判断该国处在哪条路径上。不同路径的「不稳定」含义完全不同，用同一套指标横跨比较是方法错误。

3.1 四条路径（原三条 + 新增一类）

路径特征机制判定信号
表达型 可见、渐进、可控 压力 → 组织化 → 制度化表达 → 政策调整 表达空间高 + 制度容量高
容量不足型 可见、慢性难收敛 诉求表达 → 国家无力回应 → 对抗升级 表达空间中 + 制度容量低
压制型 不可见、突变 压力 → 表达受阻 → 积累 → 触发事件 → 快速扩散 表达空间低 + 制度质量中等
高质量低参与型 可见但受控、高度稳定 高质量制度吸收诉求，参与渠道有限但畅通 表达空间中 + 制度质量极高

3.2 为什么新增第四类

跨国对比发现了一个框架原先无法归类的情况：两个国家可以拥有相近（甚至更低）的表达空间，但秩序的来源完全不同。

维度类型甲类型乙
表达空间中等很低
政府效能极高中等
法治极高中等
控制腐败极高中低
维持秩序的主要来源制度质量强制力
稳定的性质内生部分来自压制

类型甲的限制由高质量制度支撑——高薪养廉、强法治、高生活水平。类型乙的限制由强制力支撑——制度质量不足以自我支撑。

对 L0 的修正 不能只看表达空间单维。如果表达空间 < 40 但政府效能 > 80，不应直接判 C——因为高效能意味着秩序有其他来源。判定应改为「表达空间 × 制度质量」的二维判断。

3.3 路径判断的两个反直觉事实

事实一：低失业可能是压制的结果。 在实测样本中出现过「失业率最低但政治稳定评分也最低」的组合。动员型经济会吸收劳动力，低失业不代表社会满意。

事实二：高债务集中在高容量国家。 债务水平与稳定度在横截面上呈正相关，因为高债务国多为制度容量高的发达经济体；而债务最低的国家未必最稳定。债务是存量，不是压力——存在债务率超过 250% 而社会高度稳定的案例。

4. L2 — 动态变化分析

4.1 为什么必须分层

同一个指标在两个层次上的结论可能完全相反。多国面板的实测结果：

指标混合相关（跨国）国家内相关（去均值）解读
人均 GDP+0.60−0.55富国更稳，但增长期反而更不稳
进口占 GDP+0.64+0.00全是国家间差异
政府债务+0.37−0.03同上
失业率−0.24+0.11方向翻转

混合相关大半是国家间差异的产物。 只做跨国回归的报告会把进口、债务全列为「显著因素」，而它们对预测「某国明年会不会更不稳」毫无用处。

4.2 唯一跨层稳健的指标：通胀

层次相关系数
混合（多国面板）−0.55
国家内去均值−0.38
分国方向样本中多数国家为负，仅个别例外

这是唯一在跨国与国内两个层次都保持负相关的指标。 含义直接：同一国家通胀上升时，稳定评分确实下降。

4.3 托克维尔效应

人均 GDP 的符号反转不是均匀的——它按发展水平分组后呈现系统性差异：

国家组国内 r形态
发达民主国家组负（−0.4 至 −0.9）增长时稳定下降
新兴 / 非民主国家组正（+0.3 至 +0.8）增长时稳定上升

前一组符合托克维尔效应：经济改善期，期望上升快于实际改善，相对剥夺感反而增强。

同一经济变量的政治含义，取决于该国处在什么发展阶段。

4.4 最硬的一条

结论 没有任何经济指标在所有国家内部呈现一致方向。不存在「失业率上升 X% 就导致不稳定」这种普适规律。这解释了为何纯粹的时间序列预测路径会失败：它假设了一个跨时空稳定的关系，而该关系并不存在。

5. L3 — 因果识别

5.1 预测 ≠ 识别

预测型研究的失败原因，是宏观特征对事件无增量信息，模型捕捉的是自相关。

关键区分：

  • 预测是降低了不确定性（哪怕来自自相关）
  • 识别是归因（改变 X 会让 Y 变多少）

AUC 高不代表理解，只代表能排序。

5.2 识别设计：DID + 外生冲击

要素设计
问题从「何时发生」改为「是否导致」
方法双重差分（DID）+ 双向固定效应
处理变量外生冲击（自然灾害）
结果变量三类政治层（抗议/骚乱/镇压）+ 暴力犯罪（秩序层）
关键双向固定效应吸收全国共同趋势——那是自相关所在，是设计消掉而非回避

5.3 识别的四项前提

条件检查方法
平行趋势冲击前处理组与控制组趋势一致
无预期效应冲击不可预测（天灾满足，政策不满足）
无溢出控制组不受处理组影响（地理隔离）
排他性冲击只通过预期通道影响结果

任一条不通过，DID 结果不可用。

6. L4 — 结论形态

6.1 五种形态

形态含义触发条件
A 完整能测水平 + 能测时点L0 通过 + L3 通过
B 仅水平能测水平，不能测时点L0 通过 + L3 不通过
C 事件不可观测连水平都测不到L0 不通过（表达空间低）
D 数据不足拿不到数据数据源不可用
E 无信号数据充分但无关系L2 显示无稳定关系

6.2 为什么形态必须分这么细

因为「不可判定」≠「未检验」≠「否证」。混同会夸大否定范围。

举例：某轮研究中，若干假设因数据缺失而不可判定，另一些因研究者未做而未检验。它们既没有支持核心主张，也没有反驳它。把它们都写成「未获支持」，会掩盖真实情况。

7. 指标体系与信度分级

级别指标依据
A（跨层稳健）CPI / 通胀率混合与国内相关同向，多数国家一致
B（仅跨国有效）进口、出口、贸易占 GDP、债务国内相关接近零
B（方向依国情）人均 GDP发达国负、新兴国正
C（弱或不稳）失业率、基尼、股指波动相关弱或方向乱
元层（不作信号）表达空间、观测覆盖率只作分母与交互项
元层的特殊性 表达空间与观测覆盖率不是稳定性指标，而是测量条件。它们决定「其他指标是否可信」，本身不提供信号。这一点需要在代码层用断言锁死，防止后续分析误用。

8. 数据源可得性

实测结论（不列具体国别）：

类别源覆盖备注
国际统计World Bank接近全覆盖唯一可横向比较
金融市场Yahoo Finance汇率全覆盖、股指多数个别市场序列被下架
生产价格FRED + Eurostat约 2/3部分大型经济体缺失

各国统计各机构约半数部分站点直接不可达

新闻事件层的完全缺失，是本框架最大的约束——所有事件级分析都做不了。

9. 十条陷阱清单

来自本项目实践，按严重程度排序：

  1. 把「事件少」当「稳定」——这是最致命的。必须先做 L0。
  2. 把混合相关当因果——进口占 GDP 的国内相关接近 0。
  3. 跨政体类型比较事件计数——同样是集会，在不同制度下含义可能相反。
  4. 从局部无推全局无——「在某份案例名单里没看到」不等于「在全样本里没有」。这曾是本框架的错误判断。
  5. 忽略数据中断的时点——中断月份本身可能标记制度性断裂。
  6. 把低失业当稳定——可能是强制动员。
  7. 把债务存量当压力——需看债权结构与储备；存在高债务率但无净债务的经济体。
  8. 用「未检验」冒充「否证」——会夸大否定范围。
  9. 字段名当字段内容——NAVCO 的 loc_iso 是 COW 代码不是 ISO；World Bank indicator 接口不返回 region。
  10. HTTP 200 当下载完整——曾遇到 JSON 在数百 KB 处截断却返回 200。

11. 框架的边界

能不能
判断某国的稳定性是否可测预测某国何时失稳
判断它处在哪条失稳路径给出「不稳定指数」单一排序
筛出跨层稳健的指标（目前只有通胀）确认任何指标的因果效应（除非 L3 全过）
识别数据缺口与测量偏差替代事件级数据（新闻层缺失是硬约束）
最要紧的一句 在表达空间低的社会，稳定性本身不可测量。任何声称「这些国家更稳定」的结论，都必须先排除「观测通道被抑制」这一解释。
边界声明 本框架用于描述性风险因素分析——产出是风险地图，不是操作方案。前者可用于预警、资源配置、政策评估；后者涉及介入他国政治，不在框架范围内。
